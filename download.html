📖 Инструкция по установке:

  1. Скачайте APK файл на телефон
  2. Откройте загрузки и нажмите на файл
  3. Разрешите установку из неизвестных источников (если потребуется)
  4. Нажмите "Установить"

🍎 iPhone / iPad

Установите через App Store или PWA

Отсканируйте QR-код или откройте сайт в Safari

📖 Инструкция для iPhone:

  1. Откройте Safari на вашем iPhone
  2. Перейдите на сайт: cortez678.github.io/Bike-Trails/
  3. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
  4. Выберите "На экран «Домой»"
  5. Нажмите "Добавить" — приложение установится!

⚠️ Важно: APK файл предназначен только для Android-устройств
